### How to study
Первая версия проекта "Научиться учиться"
Сайт рассказывает о методах обучения, приведена некоторая статистика и указаны полезные ресурсы.

В следующих версиях проекта используются анимации, вставлены видео из YouTube.

Работа позволила изучить и закрепить семантическую верстку, блочную модель документа, flex-box верстку.
